# Google Slides Presentation - Creation Guide

## Quick Start

### Step 1: Create Google Slides
1. Go to [Google Slides](https://docs.google.com/presentation/)
2. Click "New" → "Blank presentation"
3. Title: "Social Media Backend API"

### Step 2: Set Up Design
1. Click "Slide" → "Change theme"
2. Choose a modern theme (e.g., "Focus" or "Shift")
3. Customize colors:
   - Primary: #667eea (Purple)
   - Secondary: #764ba2 (Dark Purple)

### Step 3: Add Slides
Create 21 slides following the content in `GOOGLE_SLIDES_CONTENT.md`

## Adding Visual Elements

### Insert Diagrams
1. **Architecture Diagram:**
   - Insert → Shapes → Use rectangles and arrows
   - Create layers: Frontend, API, Database
   - Use different colors for each layer

2. **ERD Diagram:**
   - Insert → Image → Upload ERD_DIAGRAM.html screenshot
   - Or recreate using shapes and connectors

3. **Flow Diagrams:**
   - Use arrows and shapes
   - Color code different flows
   - Add labels to each component

### Insert Code Snippets
1. Click Insert → Text box
2. Paste code
3. Format:
   - Font: Courier New or monospace
   - Size: 12-14pt
   - Background: Light gray (#f5f5f5)
   - Add syntax highlighting manually or use colors

### Insert Tables
1. Click Insert → Table
2. Set rows and columns
3. Add headers with background color
4. Format text: Bold headers, regular body
5. Use alternating row colors for readability

### Insert Images
1. Click Insert → Image
2. Upload from computer or search
3. Resize and position appropriately
4. Add captions if needed

## Formatting Tips

### Text Formatting
- **Title:** 44pt, Bold, Primary color
- **Subtitle:** 28pt, Regular, Secondary color
- **Body:** 18pt, Regular, Dark gray
- **Code:** 14pt, Monospace, Dark background

### Color Usage
- **Primary (#667eea):** Titles, main headings
- **Secondary (#764ba2):** Subheadings, emphasis
- **Accent (#5cb85c):** Highlights, checkmarks
- **Neutral:** White background, dark gray text

### Spacing
- Margins: 0.5 inches on all sides
- Line spacing: 1.5 for body text
- Padding in text boxes: 10-15px
- Space between elements: 20-30px

### Consistency
- Use same font throughout
- Consistent heading styles
- Aligned elements
- Uniform spacing

## Sharing Instructions

### Step 1: Finalize Presentation
1. Review all slides
2. Check spelling and grammar
3. Verify all links work
4. Test any embedded content

### Step 2: Share Settings
1. Click "Share" button (top right)
2. Set permissions:
   - **For mentors:** Viewer access
   - **For collaborators:** Editor access
3. Get shareable link

### Step 3: Copy Link
1. Click "Copy link"
2. Share link format: `https://docs.google.com/presentation/d/[ID]/edit?usp=sharing`

### Step 4: Set Viewing Permissions
1. Click Share → Change to "Viewer"
2. Anyone with link can view but not edit
3. Optional: Require sign-in

## Presentation Tips

### Before Presenting
- Practice with the slides
- Test all links and embedded content
- Have backup (PDF export)
- Check audio/video if included

### During Presentation
- Use presenter view (Alt+F5)
- Navigate with arrow keys or spacebar
- Use speaker notes for talking points
- Pause for questions

### After Presentation
- Save as PDF for distribution
- Export as PowerPoint if needed
- Archive presentation link
- Collect feedback

## Export Options

### Export as PDF
1. File → Download → PDF Document
2. Saves all slides in PDF format
3. Good for sharing with non-Google users

### Export as PowerPoint
1. File → Download → Microsoft PowerPoint (.pptx)
2. Maintains formatting
3. Can edit in PowerPoint

### Export as Images
1. File → Download → PNG (or JPEG)
2. Each slide as separate image
3. Useful for documentation

## Troubleshooting

**Issue:** Slides not loading
- Solution: Refresh page, clear cache, try different browser

**Issue:** Images not displaying
- Solution: Re-upload images, check file format (PNG/JPG)

**Issue:** Formatting looks different on different devices
- Solution: Use standard fonts, test on multiple devices

**Issue:** Sharing link not working
- Solution: Check permissions, verify link is correct
