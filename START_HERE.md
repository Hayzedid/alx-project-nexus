## 🆘 Troubleshooting

### Backend won't start?
```bash
cd social-media-backend
python manage.py runserver
```

### Postman not working?
- Verify backend is running
- Check endpoint: `http://localhost:8000/graphql/`
- Verify request format

### OBS not recording?
- Check display capture is selected
- Verify output directory
- Check disk space
